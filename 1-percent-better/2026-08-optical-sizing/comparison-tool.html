What to look for: compare "As shipped" to "Optical sizing" to see the effect of turning optical sizing on top of APL's current styles. For number tokens, also compare against "Optical + stock tracking" to see whether removing the manual −1px letter-spacing (an adjustment made before Inter's optical sizing existed) feels better once optical sizing is already doing spacing work on its own — if the last two look very close, the manual override is redundant and can be removed.

All values above are taken directly from APL's current tokens — including font-feature-settings (stylistic sets, tabular/proportional figures, ligatures) — nothing here changes size, weight, or feature settings. This is strictly isolating optical sizing and letter-spacing as variables so you can judge it against real APL type, not a generic scale.

Note: font-optical-sizing requires the browser to support the Inter Variable font's opsz axis (Chrome, Edge, Safari all do). The legacy serif styles (headline, subtitle, page-title, etc., which use Tiempos Headline) aren't included here since optical sizing is an Inter-specific consideration — those styles use a different typeface entirely.

Overlay mode: lets you turn on any combination of layers — zero, one, two, or all three — stacked directly on top of each other per row, color-coded (black = current APL style, purple = with optical sizing, orange = with optical sizing and the negative letter-spacing removed) using multiply blending so overlapping strokes darken. The third chip only has a visible effect on number styles, since removing the −1px tracking is specific to those tokens. This makes differences in overall word/line width and letterform shape much easier to spot than side-by-side rows — if the layers trace almost the same outline, the variants are nearly identical in width and shape at that size; if they visibly diverge or "fringe" in color at the edges of letters, that's where optical sizing or tracking is changing the letterforms or spacing.
